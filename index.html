Fortschritt sichern

Alle Häkchen, Notizen und die ausgewählte Woche werden lokal auf diesem Gerät gespeichert. Exportiere regelmäßig eine Sicherung, falls Safari-Daten gelöscht werden oder du das Gerät wechselst.

Wichtig: Eine lokal geöffnete HTML-Datei und dieselbe App auf einer Website können unterschiedliche Speicherbereiche haben. Der JSON-Export ermöglicht die Übertragung.

Auf dem iPhone installieren

  1. Die Dateien auf einer HTTPS-Website bereitstellen, z. B. GitHub Pages.
  2. Die Adresse in Safari auf dem iPhone öffnen.
  3. Auf „Teilen“ und anschließend „Zum Home-Bildschirm“ tippen.
  4. Die App künftig über das Home-Bildschirm-Symbol öffnen.

Nach dem ersten Online-Aufruf kann die installierte Version dank Service Worker offline funktionieren. Änderungen werden nur auf diesem Gerät gespeichert.
