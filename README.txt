DevSecOps Lernplan V2 – iPhone PWA

144 Tageslektionen mit Startbefehlen, Praxisübungen, Lösungshinweisen und Erfolgskontrollen.

INSTALLATION:
1. index.html, manifest.webmanifest, sw.js, icon.png und icon-512.png zusammen auf GitHub Pages oder HTTPS-Webspace hochladen.
2. In iPhone Safari öffnen, Teilen > Zum Home-Bildschirm.
3. Häkchen und Notizen werden lokal gespeichert. Im Backup-Tab regelmäßig JSON exportieren.

HINWEISE:
- Befehle sind illustrative Startbeispiele und können Versions-/Umgebungsanpassungen benötigen.
- Keine echten Secrets oder produktive Systeme für Sicherheitsübungen verwenden.
- Für automatischen Gerätewechsel ist ein JSON-Backup nötig.
- App kann nach erfolgreicher Installation offline verwendet werden; externe Lernlinks benötigen Internet.
